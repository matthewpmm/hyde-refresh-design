A large "steam boiler" prop for the [[Rooms/Boiler Room]]. This will be connected to a series of decorative pipes run around the walls of the boiler room.
# Deliverables
- One steam boiler prop containing a robust and functional fog machine ready to be connected to our COGS and DMX systems with no additional modification.
- Maintenance documentation explaining how to repair any technical issues in the future.
- A fully sourced bill of materials for ongoing maintenance.
# Design Specifications
- This should look bulky, and very steampunk/gilded age/industrial revolution era.
- This must be easy to securely fix to the floor and/or walls of the boiler room.
- This prop and all decorations attached to it must be very secure and robust, as guests will be able to touch it directly.
- A final layer of weathering/aging is not necessary - our painters and decorators can match it to the other decoration during installation.
# Technical Specifications
- This must contain a durable fog machine with a large capacity and extremely easy access for staff to refill the fog fluid reservoir.
	- The fog machine needs to be oriented such that it can shoot a jet of fog directly at the [[Props/Eye Chain]] on the [[Creative Technology/Brake Lever]] to give the impression that a jet of steam has dislodged the eyes from the brake lever.
	- This fog machine can be controllable either by DMX or a digital trigger. If the latter is the case, please set it up to trigger via a +5V signal. If a DC voltage supply is necessary, please attach a female barrel jack connector that we can use to connect to a central power supply.
- We will be running all cable connections to this prop through the floor, so it must be easy to connect any necessary input or output cables through the underside of the boiler.
