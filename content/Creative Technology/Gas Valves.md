Valves stationed at junctions along [[Creative Technology/Gas Pipes]] used to alter the flow of gas through the pipes to solve [[Puzzles/Puzzle 3 - The Gas Pump]]. They communicate information about user interaction with COGS.
# Deliverables
- (???x) functional gas valve assemblies ready to have gas pipes run through them, be installed onto various walls, and be connected to a COGS digital master.
# Design Specifications
- These should look very old-fashioned, and as non-analog as possible.
- Each valve should be emerging from the front of a box-like housing, into which 1.5" diameter pipes can be run and internal hardware can fit comfortably.
- These must be extremely durable.
- It should be relatively easy to run pipes into each 
- Each valve housing should have mounting hardware making it easy for the install team to fasten it to a wall with screws.
# Technical Specifications
- These must use [rotary encoders](https://a.co/d/04HXf6UK) so that no reset is necessary - only detecting the rotation of each valve is important, not its specific position.
- Each rotary encoder should be soldered to a female [4-pin JST connector such as these](https://a.co/d/0cV6Ah8y) (we can provide these if we happen to have extras) with the following standardized wire color coding:
	  - Black: GND
	  - Green: DT
	  - Red: +5V
	  - Blue: CLK
