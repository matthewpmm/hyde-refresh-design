# Puzzle Specifications

Spread out around the rafters of the train car are 6 [[Creative Technology/Steam Whistle]]s, from which hang pull chains with handles. Each of the pull chains has a tag on it depicting a different animal. After the [[Broken Valve + Valve Handle]] is used to allow steam to flow through the pipes, any of these chains by the handle triggers a whistle to begin blowing a unique pitch; releasing the handle triggers it to stop.

For internal and programming numbering purposes, the whistles are numbered from 1-6 in order of how far away each is from the entrance door; the closest to the door is #1 and the furthest from the door is #6.

The tag on each whistle chain from 1-6 depicts each of the following animals:

1. Elephant
2. Monkey
3. Lion
4. Seal
5. Tiger
6. Bear

Before beginning the puzzle, the [[Broken Valve + Valve Handle]] must be used to allow steam to flow through the whistles.

To solve the puzzle, guests must draw the connection between the order of the seven things mentioned and the subjects depicted on the six whistle pull chain handles, determine the correct order of the seven acts, and pull the chain with a handle depicting each act in the order above.

The matching handle subject for each of the acts mentioned is as follows:

| Whistle Number | Animal   |
| -------------- | -------- |
| 1              | Elephant |
| 2              | Monkey   |
| 3              | Lion     |
| 4              | Seal     |
| 5              | Tiger    |
| 6              | Bear     |

In terms of the whistle numbers, the solution order is 1342356. This makes the correct order identified by each animal Elephant, Lion, Seal, Monkey, Lion, Tiger, Bear.
